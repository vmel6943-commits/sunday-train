# 当前配置与扩展

## 剧情与交互

第一幕的下一步指引集中在 `game/presentation.ts` 与 `App.tsx` 的 guidedContinue，第一幕不设猜编号或机关门槛。场景热点仍可触发探索、收藏、环境与角色回应。

第二幕内容集中在 `data/event.ts`。初次判断先保存；任意材料被查看并收进记录后，就开放再次判断。调查笔记自动按材料整理信息，不做关联判分。更换材料时保留事件、视频片段、证据、投票选项与传播记录的ID一致。

第三幕的美食、广播、见闻与隐藏收藏均为可选内容，不阻止首日结尾。物品组合、拖放、分步制作与自由观察保留，避免引入没有明显提示的密码或精确目标。

## 对白来源与返回

对白会话包含scene和epoch。内部go、画内返回与路由返回会让旧会话失效；渲染时与结束回调均检查归属。新对白读取当前Store中的scene，不能使用跳转前闭包里旧的scene。面板也绑定来源场景。

增加新的导航入口时，调用统一go或交给已有路由处理，避免只修改背景而保留旧对白。打开历史或设置时保持当前对白，暂停其自动播放。

## 场景配乐

`data/music.ts`声明曲目与场景关系，`components/Music.tsx`保留两路audio元素，`utils/audio.ts`控制播放与切换。

首次播放必须由点击解锁；更换场景时使用双播放器交叉渐变；对话期间降低到正常音量的约46%；浏览器隐藏时暂停。静音与音量保存在用户设置中。背景音乐使用随包MP3，交互提示音使用Web Audio。

增加音乐时将文件放入public/music并配置路径、标题与使用场景。原始原创配乐脚本在scripts/compose-music.py；它只用于重新制作音轨，浏览器运行不需要Python或ffmpeg。

## 美术与存档

运行资源唯一索引为assets.json，原文件名、尺寸、透明通道与路径在美术资源清单.json。手机和电脑分别使用对应构图与热点。对白不再额外叠加全身人物，背景里的正式角色承担画面表演。

存档格式保持版本1，已有浏览器进度直接继续；本轮体验标记story-v2用于默认音频设置更新，显式静音记录优先保留。更改存档结构时应显式迁移。多设备与多人数据需真实后端，本版只记录个人体验。
