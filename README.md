# 开往周日的列车

【值周七组】烧鹅濑粉组呈现。以连续剧情、轻松尝试与自由探索为主的三幕互动网页。使用已有正式鹅设与场景素材，支持手机与桌面，并保留个人车票、调查记录、收藏和手账。

## 启动

需要 Node.js 22.6+ 和 npm。所有美术与MP3配乐均随项目提供，运行时不依赖外部素材网站。

```bash
npm ci
npm run dev
```

生产构建与核心测试

```bash
npm test
npm run build
```

生产文件位于 `dist/`，可部署到静态站点。使用 HashRouter，图片和音乐使用相对路径，支持 GitHub Pages 仓库子目录。

本地检查生产版可运行 `npm run preview`。直接双击 `index.html` 无法运行 React 源码。

## GitHub Pages 发布

项目包含 `.github/workflows/deploy-pages.yml`。将本目录作为仓库根目录推送到 `main`，在仓库 Settings → Pages 中将 Source 设为 GitHub Actions，然后运行发布工作流。后续推送自动重新构建并发布，Actions 的部署记录提供实际访问地址。

工作流会先执行 `npm ci`、`npm test` 和 `npm run build`，再发布 `dist/`。

[GitHub 官方发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## 三幕体验

### 第一幕：午夜发车前

拆信、到站、跟随乘务员引导、填写昵称领取车票、检票登车、展开旅途地图、认识带皮箱的旅客。

每个场景都有明确的“继续旅程”入口。信件回应和票面偏好可以自由选择；昵称可以留空使用“鹅鹅旅客”。移除了猜编号、激活机关与必须寻找物品才能推进的条件。拖票检票与点击检票均保留，怀表、报纸、长椅、行李和铃铛可以继续探索。

### 第二幕：皮箱里的十五秒

阅读《列车专报》，留下初次判断，跟周紫琳打开皮箱。视频、公告、时间线、现场证词与传播记录均可自主选择阅读顺序。任意一份材料收进记录后，即可留下再次判断，也可以继续查看其他材料。

保留真实可操作的分镜播放/暂停/定位、公告连续对比、卡片移动、证词高亮与措辞追踪。开箱没有密码，时间线没有答错惩罚；调查笔记按所读材料整理事实、不同说法与疑问。观点没有正确立场，前后两次判断独立保存。

当前图书馆案例为明确标注的虚构演示，可在 `src/data/event.ts` 替换。

### 第三幕：夜行列车奇遇记

五个车厢区域自由往返：乘客车厢、观景走廊、列车餐车、广播角、手账台。

保留个人座位、灯光开关、旧照片翻面、移动望远镜、月光纪念柜、唱针与留声机组合、旧车票与角色回应、秘密菜单、食谱、配料组合、制作动作、纪念印记、自定义美食名称和分享卡。

广播旋钮可以随意转动，广播片段随时可以点击；纪念柜的三个图案按任意顺序触碰都能开启。见闻、美食、广播与隐藏收藏均为自由探索，随时可以到手账台收藏首日记录，结尾后仍可回到列车。

## 对白与场景同步

- 对白改为轻量的电影字幕式面板，保留小头像与姓名，取消额外的大幅人物立绘。
- 对话期间收起场景热点与标题，保留场景中的原始角色。
- 每段对白与面板都绑定来源场景；场景切换、画内返回、浏览器返回/前进立即清理旧界面。
- 对白结束回调同时检查来源场景与会话编号，失效的旧回调无法推进新场景。
- 对话历史与设置面板打开时，自动播放暂停。
- 点击正文可以补全文字或继续，支持自动播放、已读跳过、可选回应与收起对白。

## 场景配乐

随包包含6首原创器乐循环，单首约40—57秒：

| 场景 | 曲名 | 氛围 |
| --- | --- | --- |
| 邀请函 | 一封午夜来信 | 钟琴、轻钢琴 |
| 到站、领票、站台 | 最后一声汽笛 | 三拍启程曲 |
| 情报与调查 | 皮箱里的回声 | 轻拨弦、钟琴 |
| 车厢、观景走廊、广播角 | 月光越过车窗 | 舒缓夜行曲 |
| 餐车 | 餐车的甜点华尔兹 | 轻快钢琴 |
| 首日结尾 | 把今夜好好收藏 | 温柔收束 |

首次主动开始旅程后播放；场景变化时约1.8秒淡入淡出，对话时降低音乐，离开页面暂停。顶部可静音或恢复，设置中可调音量，选择会保留。所有配乐为本项目原创程序作曲与合成，未使用外部采样。曲目数据与来源见 `public/music/credits.json`。

## 数据与扩展

- 同一浏览器localStorage自动存档，支持JSON导入/导出。保留兼容旧版存档，不要求重新开始。
- 两次投票与把握程度分别保存，故事中的人物读取真实昵称、座位、调查与收藏状态。
- Canvas导出专属车票、观点卡、美食卡与首日纪念卡；支持隐藏昵称/观点、复制链接与文案，浏览器支持时可系统分享。
- 周二至周日保留锁定预告，等待实际活动安排。
- 当前没有账户、跨设备同步、多人统计或真实抢座。
- 配乐生成脚本需要NumPy、SciPy与ffmpeg，美术重建脚本需要Pillow；日常运行与部署直接使用已提供的资源，无需执行这些脚本。

测试记录见 `docs/测试报告.md`，原始美术来源见 `docs/美术资源清单.json`。微信内置浏览器与真实iOS/Android的声音、系统分享和保存图片仍需活动前实机走查。
